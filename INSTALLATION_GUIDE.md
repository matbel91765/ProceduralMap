# 📦 Guide d'Installation - Ultimate Procedural Map

## Option 1 : Utiliser comme Projet Standalone ⭐ RECOMMANDÉ

### Étapes d'installation :

1. **Cloner ou télécharger le repository**
   ```bash
   git clone https://github.com/matbel91765/ProceduralMap.git
   cd ProceduralMap
   ```

2. **Ouvrir avec Unreal Engine**
   - Double-cliquer sur `ProceduralMap.uproject`
   - Unreal Engine va détecter qu'il faut compiler
   - Cliquer "Yes" pour compiler

3. **Compilation**
   - L'éditeur va lancer la compilation automatiquement
   - Attendre la fin (peut prendre 5-15 minutes la première fois)
   - L'éditeur s'ouvrira une fois compilé

4. **Vérification**
   - Aller dans `Edit > Plugins`
   - Vérifier que "Procedural Mesh Component" est activé
   - Vérifier que "Water" est activé
   - Redémarrer si nécessaire

### ✅ C'est tout ! Le projet est prêt à l'emploi.
